# 拆书工具系统

## 项目目标
构建一个复杂工具系统，用于执行中长篇小说的拆书和人物分析工作。

---

## 核心工作流程

```
原始小说 → 结构扫描 → 用户确认拆分粒度 → 执行拆分 → 生成报告
                                              ↓
                              [用户主动触发的后续任务]
                              ├─ 分章节概括
                              ├─ 人物概括
                              ├─ 事件概括
                              └─ ABC爽点分析
```

---

## 功能模块

### 模块一：智能结构扫描（拆分扫描）

**触发方式**：用户提供小说文件后自动执行

**扫描内容**：
- 检测文件编码（UTF-8/GBK/GB2312）
- 识别章节层级结构（卷→章→节→话 等）
- 统计各层级数量
- 识别特殊标记（序章、番外、终章等）

**输入格式**：txt、epub

**输出格式**：.md 文件

**命名规范**：
```
001_第一章_标题.md
002_第二章_标题.md
...
048_番外_标题.md
```

### 模块二：分章节概括

**架构**：主调度 + 分组 sub-agent（每组3章，约500字概括）
- 滚动上下文机制
- 故事概要四栏目动态更新
- 名词表动态维护（只增不改）
- 断点续传 + 指定重做

### 模块三：人物关系概括

**架构**：拟人阅读模式
- 先假设→带问题阅读→持续记笔记→归纳
- 输出：角色地位.yaml + 人物关系.yaml + 关系图谱.md

### 模块四：事件线追踪

**架构**：拟人确认模式
- 先梳理→审视→有疑问回原文确认
- 输出：事件线.yaml + 时间轴.md

### 模块五：ABC爽点分析

**架构**：并行 sub-agent
- A（铺垫共情）B（装逼+反应）C（钩子）结构分析
- 输出：abc-ch{XXX}.yaml + abc-summary.yaml + abc-heatmap.md

## 目录结构规范

每本书独立目录，统一结构：

```
{工作目录}/
└── {书名}/
    ├── {书名}.txt               # 源文件
    ├── 拆分/                    # 章节拆分文件
    │   ├── 001_第一章_xxx.md
    │   └── ...
    ├── 概括/                    # 分章节概括
    │   ├── 组1_第1-3章_概括.md
    │   └── ...
    ├── 人物和设定/              # 人物分析
    │   ├── 名词表.md
    │   ├── 角色地位.yaml
    │   └── 人物关系.yaml
    ├── 事件线/                  # 事件追踪
    │   ├── 事件线.yaml
    │   └── 时间轴.md
    ├── ABC分析/                 # 爽点分析
    │   ├── abc-ch001.yaml
    │   └── ...
    ├── 全书概括.md
    └── 关系图谱.md
```

## 依赖关系

```
拆分扫描
    │
    ▼
分章节概括
    │
    ├──→ 人物概括
    ├──→ 事件概括
    └──→ ABC爽点分析
```

## 自动化模式

`自动化拆书` = 拆分扫描 → 分章节概括 → 人物概括 → 事件概括 → ABC分析
