# ABC爽点分析法——AI识别规则定义文档

> **版本**：v1.0
> **用途**：供 abc-fenxi skill 的 sub-agent 使用，定义如何识别和评分章节的 ABC 结构
> **来源**：基于二宝 ABC 拆书法理论 + webnovel-editor.md 商业操盘手框架

---

## 核心前提

**小说是情绪结构产物，不是现实逻辑。**

ABC 分析的目标是识别每个章节中的「情绪驱动循环」——读者感到爽是因为期待被兑现（A→B），而不是因为情节本身合理。

---

## A — 动机 + 共情（暗爽）

### 定义

A 是主角在本段情节中的**目标或处境**，以及作者用来让读者**理解和代入主角**的所有手段。

A 产生的是「暗爽」——读者还不知道结果，但已经开始期待了。

### AI 识别标准

以下任意一种出现，即可识别为 A：
1. **目标铺垫**：主角明确说出或心里想着「我要做某件事」
2. **处境共情**：主角被质疑、被打压、被误解、被小看——读者代入弱者视角
3. **能力暗示**：隐藏实力、神秘背景、未被发现的金手指——读者知道主角有牌
4. **心理独白**：主角内心戏（「他们不知道我的实力」「总有一天」）
5. **矛盾设置**：外界认知与主角实际状态之间存在落差

### 强度评分（1-5星）

| 分值 | 标准 |
|------|------|
| ★☆☆☆☆ | A 几乎没有铺垫，读者无法代入主角动机 |
| ★★☆☆☆ | 有基本的目标说明，但共情感薄弱 |
| ★★★☆☆ | 主角目标清晰，有一定铺垫，读者能理解 |
| ★★★★☆ | 铺垫充分，共情感强，期待感明显 |
| ★★★★★ | 铺垫精准，落差感极强，读者迫切想看 B |

### 常见问题

- ❌ **A 太长**：铺垫超过全章 50% 而没有推进 B
- ❌ **A 太短**：不到一句话就直接进装逼，读者没有期待感
- ❌ **无共情**：主角的动机读者不在乎（如：「我要修炼」而没有任何情感驱动）

---

## B — 装逼 + 反应（明爽）

### 定义

B 是 A 铺垫的**情绪兑现时刻**，包含两个必须的子元素：
- **装逼**：主角展示实力/价值/判断力的行为本身
- **反应**：周围人物对装逼行为的反应

**⚠️ 核心原则：反应比装逼更重要。**
装逼可以几个字，反应必须浓墨重彩，篇幅是装逼的 2-3 倍。

### AI 识别标准——装逼

装逼的形式多种多样，以下均可识别为「装逼」：
1. **实力展示**：战斗胜利、炼丹成功、修炼突破
2. **知识/判断力**：准确预言、识破阴谋、道破本质
3. **逆转打脸**：被嘲讽后当场反击、被质疑后立即证明
4. **间接揭露**：别人代为揭露（「你知道他是谁吗！」）
5. **被动展示**：主角无意中展示了超常能力/背景

### AI 识别标准——反应

反应必须是**其他人物或环境**对装逼的具体回应。

**标准分层模板**（不要求全部出现，至少要有 2 层）：

| 层级 | 内容 |
|------|------|
| 第1层：质疑者 | 之前不信主角的人愣住、沉默、表情崩裂 |
| 第2层：围观群众 | 大量NPC哗然、议论、震惊 |
| 第3层：嘲讽者 | 曾经嘲讽过主角的人脸色铁青、后悔、羞愧 |
| 第4层：强者/美女 | 重要人物重新审视主角、开始重视 |
| 特殊层：扩散效应 | 消息传播出去，更广泛范围的震动 |

### 强度评分（1-5星）

| 分值 | 标准 |
|------|------|
| ★☆☆☆☆ | 只有装逼，完全没有反应，或反应只有「众人震惊」一句话 |
| ★★☆☆☆ | 反应存在但只有 1 层，且篇幅不足装逼的 1 倍 |
| ★★★☆☆ | 反应有 2 层，篇幅接近装逼 1-2 倍 |
| ★★★★☆ | 反应有 3+ 层，篇幅达到装逼 2 倍，情绪传达清晰 |
| ★★★★★ | 反应分层 4+，篇幅达装逼 3 倍，有扩散效应，读者高度代入旁观者视角 |

### 反应篇幅比计算

```
反应篇幅比 = 反应段落字数 / 装逼段落字数
目标值: ≥ 2.0
合格值: ≥ 1.5
警告值: < 1.0
```

### 常见问题

- ❌ **无反应**：主角展示完实力后直接切到下一个场景
- ❌ **反应不分层**：只写「众人震惊」「大家都愣住了」，没有具体人物的具体反应
- ❌ **装逼 > 反应**：花大篇幅描写如何打败对手，只用一两句话写别人的感受
- ❌ **错误的反应**：反应的是无关紧要的人（读者不在乎的 NPC），没有嘲讽过主角的人的反应

## C — 嵌套 + 突然（立体防单调）

### 定义

C 解决「如何写长、如何不重复」的问题，通过两种手段维持读者黏性：
- **嵌套**：在当前 A/B 还在进行时，提前埋入下一个循环的 A1；B 结束后立刻引出 B1 或新的 A1
- **突然**：意料之外的发展打破了读者的预期，激发「这是什么情况」的好奇心

### AI 识别标准

以下情况识别为 C：
1. **结尾钩子**：章末出现新悬念、新威胁、新任务（最常见的 C 形式）
2. **叙事中断**：B 尚未完结时，插入一个新的问题打断流程
3. **意外身份/能力**：主角或对手突然显示出意料之外的一面
4. **计划外事件**：系统通知、重要人物到来、新信息揭露
5. **规模扩大**：从小范围装逼扩散到更大范围的关注

### 层级说明

```
大循环（数章 ~ 数十章跨度）
  └─ 主线 A/B/C 推进全书主要冲突

中循环（单章内）
  └─ 章节内部的完整 A→B→C 结构

小循环（段落级）
  └─ 对话/动作中的微型期待-释放-引申
```

识别时默认记录**中循环**（章节级别）。如果发现明显的跨章大循环节点，在 `cross_chapter_note` 字段另行标注。

### 强度评分（1-5星）

| 分值 | 标准 |
|------|------|
| ★☆☆☆☆ | 章节结尾平淡，没有任何悬念或下一循环的引导 |
| ★★☆☆☆ | 有基本的结尾悬念，但感觉是硬加的 |
| ★★★☆☆ | C 自然地从 B 延伸出来，下一章的 A 已经埋好 |
| ★★★★☆ | C 意料之外，但回头看又合情合理，读者想立刻翻下一章 |
| ★★★★★ | C 产生了规模扩大/身份反转/隐藏线浮出，让整个故事升维 |

## ABC 密度计算规则

```
单章 ABC 完整度 = A完整 + B完整 + C存在
  - A完整: A强度 ≥ 3星
  - B完整: B强度 ≥ 3星 且 反应篇幅比 ≥ 1.5
  - C存在: C强度 ≥ 2星

全书 ABC 密度分级:
  高密度: ≥ 70% 章节 ABC 完整
  中密度: 50-70% 章节 ABC 完整
  低密度: < 50% 章节 ABC 完整
```

---

## 多循环章节的识别规则

有些章节（特别是长章节）包含多个完整的 ABC 循环。识别规则：
1. 一个章节内**最多识别3个主要循环**（cycle_1, cycle_2, cycle_3）
2. 如果循环超过3个，只记录强度最高的3个
3. 每个循环之间必须有清晰的节奏转换（新场景或时间跳转）

## 题材适配说明

不同题材的「装逼」形式不同，识别时需灵活适配：

| 题材 | 典型装逼形式 | 反应核心 |
|------|------------|---------|
| 修仙/武侠 | 实力展示、突破境界、秒杀对手 | 门派/同修的震惊 |
| 都市重生 | 知道未来、预测准确、商战胜利 | 昔日看不起的人后悔 |
| 无敌文 | 碾压式胜利、花样羞辱反派 | 大量 NPC 膜拜、反派绝望 |
| 系统文 | 获得稀有技能/物品、数据暴增 | 系统提示 + 旁观者反应 |
| 校园文 | 考试第一、赛场逆转、身份揭露 | 同学/老师惊讶重评 |

## 过渡点识别

### 定义

**过渡点**是指一个情节同时承担两个功能：
- 当前循环 B 的延伸（反应/收尾）
- 下一循环 A 的开始（新动机/新处境）

这种双重身份的情节点是「旧循环结束即是新循环开始」的具体表现，标记为 `B→A'⟳`。

### 5种典型场景

| 场景 | 当前循环B功能 | 下一循环A'功能 | 示例 |
|------|-------------|--------------|------|
| 反应扩散引出新敌 | 装逼的名声传播 | 新对手因名声前来挑战 | 打败弟子→师父找上门 |
| 胜利后代价揭示 | 战斗胜利的收尾 | 代价成为新处境/新目标 | 赢了比赛→发现中毒 |
| 奖励即考验 | 获得奖励（B的延伸） | 奖励本身是新挑战的入口 | 获赐神器→神器有试炼 |
| 第三方介入 | 见证反应（扩散效应层） | 第三方带来新任务/新信息 | 长老震惊→直接收徒+派任务 |
| 信息更新 | 装逼后获得新情报 | 情报揭示更大危机 | 审问敌人→得知幕后黑手 |

### 标记规则

- **tag**：`B→A'⟳`
- **note格式**：`"过渡：{B功能}+{A'功能}"`
  - 示例：`"过渡：名声传播+新对手登场"`
- 在 quick_list 中，过渡点只占一条（不拆成两条）

### 非过渡点排除

以下情况**不是**过渡点，不标 `B→A'⟳`：
- **纯悬念钩子**：章末抛出悬念但不承担当前循环B的功能 → 标 `C`
- **有明确场景切换**：B结束后切换场景再开始新A → 分别标记为独立的 `B` 和 `A`
- **时间跳跃**：B收尾后跳过一段时间再展开新情节 → 不算过渡

## 输出要求

完成分析后，sub-agent 必须进行自我审查：

**自审清单：**
1. [ ] B 的反应篇幅比是否达到 1.5 以上？
2. [ ] 反应是否有至少 2 层不同人物的不同反应？
3. [ ] A 的强度评分是否反映了读者实际的期待感强度？
4. [ ] C 是否真正存在（不是强行赋予 C 而实际没有）？
5. [ ] 循环识别数量是否合理（1-3个，不要强行识别）？
6. [ ] quick_list 中的过渡点（B→A'⟳）是否正确识别？非过渡点是否误标？

如果自审发现问题，必须修改评分或描述，然后在 `self_review_notes` 字段记录修改原因。
